# leiskill 新手入门

安装成功后重启助手，新建聊天输入 `/lei 新手入门`。只要说明手上有什么和想拿到什么，不需要先选择技能。

## 有字幕和素材，想剪一条视频

```text
/lei 字幕是 D:/Videos/input.srt，素材在 D:/Videos/source。
目标约 2 分半，先给原始时间码删留建议，等我确认再做独立剪映草稿。
```

助手先检查字幕的衔接、冗余和信息密度，说明切点理由、风险与预计时长。只有用户确认后才进入媒体处理。默认无字幕，想要字幕需在确认切点时明确提出。

## 切点已确认

提供已确认 manifest 路径、素材目录和独立工作目录，直接使用 `/jj`。已有确认记录不需要重复审稿；无法可靠映射源素材时先解决定位问题。

## 接着昨天做

```text
/lei 继续 D:/VideoProjects/demo，先看项目状态，只推进下一个未完成阶段。
```

不要把多个视频混进同一个状态文件。没有唯一项目路径时，助手先列候选或询问，不猜测。

## 装好但报错

用 `/lei-doctor 检查本机环境`，获得 Python、FFmpeg、剪映与审稿依赖的逐项结果。检查不修改已有工程。缺少剪映时先安装并打开一次；自定义路径见 [安装与排障](安装与排障.md)。

## 更新

输入 `/lei-update 更新 leiskill`。更新前备份同名技能，复用已有运行环境，不改素材、SRT、工程和项目状态。更新完成后重新打开助手。

## 你最后应拿到什么

一份可编辑草稿、原始素材引用、结构检查结果、视频标题与海报标题，以及明确的未验证事项。结构通过不代表在剪映里已播放或导出，后两项单独验收。
