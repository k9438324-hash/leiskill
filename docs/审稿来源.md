# 审稿来源与验证边界

## 本次独立实现

0.9.0 根据用户确认的“用独立流程替换外部审稿依赖”任务，在 leiskill 中新增审稿说明和本地校验脚本。实现依据是用户提出的具体交付要求：保留原始 SRT 文本与时间码、记录删留及重排、核对时长、等待用户确认后才执行。

- `skills/jj/references/srt-review.md`：任务与原话对应、删留清单、重排语义检查、用户确认和阶段交接。
- `skills/jj/scripts/review_srt.py`：UTF-8 SRT 解析、SHA-256 来源校验、原话与边界回填、完整覆盖、重复引用、顺序和时长核验。
- `tests/test_review_srt.py`：仅使用本项目创建的合成字幕与提案验证行为，不读取客户素材或外部 Skill 的测试材料。

脚本由本项目新增，只使用 Python 标准库；没有导入、下载、运行或嵌入第三方审稿 Skill 的正文、脚本及词表。流程不照搬其段落评估模板。仓库对工具箱目录组织方式的参考仍保留在框架对照中，不将参考项目标成运行依赖。

## 能做与不能证明的事

原话、编号、时间和源文件指纹可以机械核对；剪辑是否有吸引力、问答重排是否改变含义仍需要人工或模型审阅。校验通过不代表用户已确认，不证明完播率、获客或成片质量。

检查结果始终 human_approved=false、media_processing_allowed=false。确认记录应由实际用户确认后写入另一个执行 manifest。

## 变更范围

本次移除外部审稿技能的安装、调用和环境检查，不删除用户原先独立安装的任何 Skill。仅替换审稿环节；剪映草稿加解密、软件协议、其他依赖许可及经营合规分别处理，不能据本次替换宣称整个产品已经取得商用授权。
