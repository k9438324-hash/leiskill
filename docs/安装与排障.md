# 安装与排障

## 支持范围

当前视频运行重点为 Windows + 剪映专业版。用户可把 [README 的通用安装指令](../README.md#快速开始) 发给 Codex、Claude、豆包、WorkBuddy 等 AI；是否能直接执行取决于当前客户端的本机工具和 Skills 能力。纯聊天窗口应给出手动操作，不声称已安装。

Python 3.12、Git、Node.js 可由 Windows 安装脚本通过 winget 补装。没有 winget 时安装 Microsoft App Installer，或手动安装这些工具后重试。安装器不处理 AI 客户端登录。

## 一键安装与更新

```powershell
& ([scriptblock]::Create((Invoke-RestMethod 'https://raw.githubusercontent.com/k9438324-hash/leiskill/main/install.ps1')))
```

默认四个技能安装到当前用户公共技能目录，外部 dbs-script-flow 仅缺失时补装。本仓库已有同名技能更新前复制到 `%LOCALAPPDATA%/leiskill/backups/日期时间/`。备份不上传，用户可用于恢复个人修改。
公共入口为 `~/.agents/skills`；检测到已安装的 Claude Code 时通过 Skills CLI 配置其入口（支持 CLAUDE_CONFIG_DIR）；检测到 `~/.workbuddy` 时为四技能与审稿依赖创建目录 Junction。不会为未安装的客户端创建主目录。WorkBuddy 同名入口已存在且不是指向同一公共技能的链接时，保留并报告冲突，不替换用户文件。
豆包未使用固定的本机技能目录；具备技能导入能力的版本按它的实际界面导入，普通聊天版无法直接完成本机安装。其他系统可安装技能文件，当前不包含完整 Windows 剪映运行环境。
默认使用 `%LOCALAPPDATA%/leiskill/venv/` 独立环境；旧版 `%LOCALAPPDATA%/jj-skill/venv/` 已存在时复用。脚本不会移动或删除它。

## 只检查安装前提

```powershell
& ([scriptblock]::Create((Invoke-RestMethod 'https://raw.githubusercontent.com/k9438324-hash/leiskill/main/install.ps1'))) -CheckOnly
```

不安装技能或工具、不访问视频。能下载脚本不等于所有依赖都已安装。

## 使用正确 Python

安装器将实际解释器路径保存到 `%LOCALAPPDATA%/leiskill/runtime.json`，并设置当前用户 `LEISKILL_PYTHON`。助手先读此变量；没有变量时检查新版和旧版环境。手动安装的人可以使用已验证的其他 Python，但所有脚本与子进程应使用同一个解释器。

```powershell
& $env:LEISKILL_PYTHON -X utf8 "$env:USERPROFILE/.agents/skills/jj/scripts/doctor.py"
```

设置用户环境变量后，其他应用需重启才能读到。字体只在用户开启字幕或文字 overlay 时需要；仓库不分发字体。faster-whisper 只在请求转写时按需安装。

## 剪映路径异常

剪映需安装并打开一次，创建用户数据目录。默认从当前用户 LOCALAPPDATA 查找。自定义路径在运行助手前设置：

```powershell
$env:JY_INSTALL_DIR = 'D:/Apps/JianyingPro/版本号'
$env:JY_USER_DATA = 'D:/JianyingUserData'
$env:JJ_FONT_PATH = 'D:/Fonts/subtitle.ttf'
```

示例需换成本机真实路径；JY_INSTALL_DIR 应含 JianyingPro.exe。未通过的检查会阻止安装器显示成功。已有工程不受环境检查修改。

## 下载或依赖失败

保留完整错误和退出码，确认 GitHub、npm 与 Python 软件源可访问，再从安装入口重试。不要通过删除素材或工程来修复安装问题。Windows 安装完成但当前窗口找不到命令时重开 PowerShell。

## 恢复个人技能修改

关闭助手后，从备份目录选取对应技能恢复到原安装目录；不要覆盖其他技能。运行环境与项目素材分别保留。未确认备份内容前不自动删除旧副本。
