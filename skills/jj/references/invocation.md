# 调用模板

## 新视频

```text
使用 /jj 处理一条全新视频，不读取其他视频聊天。

账号：
视频目标：
目标受众：
期望时长：
原素材绝对路径：
带时间码SRT绝对路径：
待处理剪映草稿或账号母版：
验收结果：独立、可继续修改的剪映草稿

只处理本视频；优先复用缓存和母版。先用 /dbs-script-flow 检查 SRT 并给我审核带原始时间码的候选切点，确认后 /jj 只执行切点。字幕默认关闭。不要全盘扫描，也不要输出完整草稿JSON或源码。
```

已有确认切点 manifest 时可以不提供 SRT；否则必须提供带时间码 SRT。用户明确的期望时长不可被历史模板覆盖；“约2.5分钟”记录为目标150秒、验收135—165秒。

## 继续当前视频

```text
使用 /jj 继续当前视频。读取 project-state.json 的紧凑状态，只执行下一个未完成阶段；复用所有已锁定结果和缓存。返回本次产物、时长验证、验证结果和下一步。草稿完成后直接给出视频标题和海报标题。
```

## 额度止损

```text
使用 /jj 检查当前视频的额度消耗。只读取 project-state.json、预算记录和阶段摘要；指出正在重复的步骤，停止超限阶段，并交付已锁定结果与最小续接入口。
```

安装工具、修改 Skill、设计新工作台或跨多条视频复盘不属于本 Skill。为这些任务另开聊天，避免污染单条视频上下文。
