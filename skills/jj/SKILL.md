# `/jj` 短视频剪辑工作台

目标是交付一条可检查、可继续修改的短视频草稿，同时控制主模型读取量。模型只做会改变内容判断的工作，本地脚本负责重复、确定的媒体处理。

新建剪映草稿默认使用 60 fps；保留源素材原始帧率，不做补帧。此默认值仅用于后续构建，已生成草稿保持原样。

## 任务隔离

- 一条视频对应一个聊天、一个项目目录和一份 `project-state.json`；状态文件代替跨视频聊天历史。
- 生产任务只处理当前视频。安装工具、修改 Skill、研究新流程和额度复盘进入单独聊天。
- 新任务先按 [调用模板](references/invocation.md) 固定账号、目标、素材、草稿或母版、时长和验收条件。信息足以定位时直接执行，只追问一个会改变交付物的问题。
- 用户说“继续”时先读取当前项目的紧凑状态，只推进下一个未完成阶段；没有唯一项目状态时先报告候选项目，不猜测。

## 工作方式

1. 先运行 `scripts/workbench.py content-gate` 判断文字入口。已有用户确认的切点 manifest 时直接进入执行；有带时间码 SRT 时先调用 `/dbs-script-flow`；两者都没有时停止并只索取 SRT。闸门通过前不入库、不转写、不生成代理或联系表。
2. `/dbs-script-flow` 只检查 SRT 的逻辑衔接、冗余、信息密度和流失点，并交付可追溯的候选切点；具体格式见 [SRT 删稿与切点交接](references/srt-script-flow.md)。先让用户确认，确认后才写入 `human_approved=true` 的切点 manifest。
3. 对已有项目运行 `scripts/workbench.py status`。已有缓存和锁定结果必须复用；确认切点后只按 manifest 定位素材和精确裁切，不重新删稿、改顺序或补选内容。
4. 未建项目时按 [SOP](references/sop.md) 初始化。目标时长以用户明确要求为准；用户只说“约2.5分钟”时使用目标150秒、验收135—165秒。
5. 模型只处理 `candidates.json`、阶段manifest摘要和受限联系表。
6. 每次模型审阅前运行 `record-review`，同时记录阶段、模型等级、输入字符、图片、耗时和调用次数。
7. 按 `script → audio → visual → overlay` 锁定。文字确认后生成声音切点和预览供 QA 留档，但默认不要求用户试听或再次确认；本地时长、源区间和接缝构建检查通过后，直接进入 `prepare-visuals`。只有自动检查失败、切点无法可靠映射或发现明确音频异常时才暂停并报告。
8. `script.items` 必须是逐句字幕，不是段落摘要：默认每条不超过12个可见字符，同一时刻只显示当前一句，相邻字幕不得同文重复，时间不得重叠。构建器在锁定、预检和写草稿时三次检查，任一失败就停止。
9. 脚本锁定、声音预览、画面预检、剪映构建和最终验证都检查预计或实际时长。低于或高于验收区间时阻止锁定/构建；合格内容不足时明确报告，不能用重复废话补时长。
10. 构建前准备一个视频标题和一个20字以内的海报标题。字幕默认关闭；只有用户在确认切点时明确要求字幕，manifest 才设置 `subtitle.enabled=true` 并使用 `dalian-zhangge-sanjisonghei-10.7` 模板。运行 `preflight`；通过后生成独立、可编辑草稿并保留原工程。构建成功必须同时通过标准文件、加密回读、库加载、素材引用、源路径、轨道重叠、草稿注册和时长检查。

## 聊天名称

独立草稿构建并验证成功后，交付前执行 [聊天改名](references/chat-title.md)：将当前 Codex 左侧聊天标题改为 `qa/build.json` 中 `draft` 路径的末级名称，保留时长、帧率等后缀。优先使用 `set_thread_title`；工具不可用时尝试已提供的桌面控制能力，在界面中改名并验证。把结果单独记录为 `qa/chat-title.json`，只有实际改名并验证成功才报告已改名。草稿验收和聊天改名分别报告状态；改名受阻不重剪视频。用户反馈“项目名字没改”且指向侧栏时，直接补做此步骤。构建未成功时保留当前聊天名。

## 决策边界

- `/dbs-script-flow` 负责 SRT 主线、删留、衔接和流失风险；`/jj` 接收用户确认的切点后只做执行与验证。
- 快速模型只做候选粗分类、字幕分屏、已锁定标题和错误归类；最多两次。
- 扫描、指纹、转写、关键词检索、代理、联系表、时间换算、草稿生成和QA均本地执行。
- `/dbs-script-flow` 只读取用户指定的 SRT；切点确认后 `/jj` 不再读取完整逐字稿、完整素材目录或完整草稿JSON，失败时只读取错误附近的最小上下文。
- 同一素材以内容指纹缓存，文件名不是唯一身份。
- 媒体代理和联系表写入临时文件，成功后才替换正式缓存；中断或失败必须终止本次子进程并清理残片。
- `index-manifest-sources` 只合并manifest引用，不得删除已有同项目素材索引或B-roll候选。
- 模板草稿只提供样式，不能据此认定新项目原素材。
- 参考成片只提供结构和节奏。具体报价、户型、客户原话、墙体判断和现场事实不得写成通用规则或移植到新视频。
- 普通口播字幕不加表达性标点，删除句首句尾无信息语气词；音频只有能无损独立切除时才删，不能破坏作者声音。
- Overlay Studio只接收已锁定标题、章节字、关键词和CTA；`overlay-handoff`生成受限任务包。扩展不可用、资产缺失或格式不受支持时回退剪映原生文本。

需要开始新任务或交接其他Agent时读取 [调用模板](references/invocation.md)。收到 SRT 或确认切点时读取 [SRT 删稿与切点交接](references/srt-script-flow.md)。需要命令、预算、锁定规则和停止条件时读取 [SOP](references/sop.md)。需要编写或校验manifest时读取 [数据契约](references/schemas.md)。


## 首次安装

首次运行、换电脑或依赖报错时先读 [安装与环境检查](references/install.md)，运行 doctor.py；技能安装成功不等于剪映运行环境可用。

运行任何 Python 命令前，优先读取环境变量 `LEISKILL_PYTHON`；否则依次检查当前用户 `%LOCALAPPDATA%/leiskill/venv/Scripts/python.exe`、旧版 `%LOCALAPPDATA%/jj-skill/venv/Scripts/python.exe`。找到后，用该解释器运行本技能所有脚本和子进程；均不存在时使用已核验依赖的 Python，不混用解释器。PowerShell 示例见 [安装与环境检查](references/install.md)。
