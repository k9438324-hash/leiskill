# 更新剪辑技能

只在用户明确要求更新或重装 leiskill 时执行。剪辑过程中不主动更新，以免破坏阶段缓存和正在进行的任务。

1. 保留当前项目路径与阶段状态。只允许操作 leiskill 的四个技能入口和它的独立运行环境；不覆盖视频、SRT、原剪映工程或 project-state.json。
2. Windows 使用 [官方更新入口](references/update.md)。默认更新会备份已有的同名 leiskill 技能；自定义过的脚本可从备份恢复。审稿流程随本仓库安装，不安装、更新或删除其他技能。
3. 安装结束读取四个技能的 metadata.version，运行环境检查。命令失败保留原始错误和退出码，从失败步骤续接，不把“已给命令”写成“已更新”。
4. 输出实际版本、备份路径、环境结果，以及仍需用户完成的事项。需要重启助手才能重新发现技能时说明。

用户只问版本或更新内容时先读当前技能版本与官方 VERSION，不因此执行安装。
