# 检查剪辑环境

用户要求首次检查、换电脑或排查依赖时，运行本技能 [环境检查入口](scripts/check.py)。脚本定位已安装的 jj 并调用它的 doctor.py；不扫描素材、不安装软件、不创建工程。

1. 按 LEISKILL_PYTHON、新版本地独立环境、旧版独立环境、已核验 Python 的顺序选择解释器。见 [运行方式](references/runtime.md)。
2. 在当前用户环境运行 `scripts/check.py`，保留退出码和逐项结果。若找不到 jj，报告技能缺失；若 JSON 含失败项，只针对失败项给出修复动作。
3. 选用字幕时才要求字体；ffprobe 缺失为可选提示。转写模型只在用户请求转写且获准处理素材时安装，不为已有 SRT 流程预下载。
4. 安装或修复需要用户请求；已授权时按官方入口执行，否则只交出具体命令。检查失败不能报告可用。

环境通过只证明可执行文件、模块与路径可发现。实际草稿加密构建、剪映播放和导出分别验收。
